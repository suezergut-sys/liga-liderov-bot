# История изменений

## 0.1.0 — 2026-08-10

- Создан первый рабочий прототип панели семи команд.
- Добавлен двухэтапный сценарий, подтверждение решения и загрузка Excel.
- Реализованы глобальный таймер, принудительный выбор организатора и Telegram webhook-контур.
- Добавлены demo-режим, базовая аутентификация и unit-тесты.
- Создан Supabase PostgreSQL-проект и добавлена начальная схема игровых данных.
- Добавлена безопасная health-проверка подключения к базе.
- Игровой API переведён на транзакционное хранение состояния в Supabase PostgreSQL.
- Сохранены постоянные привязки капитанов, решения, файлы, журнал событий, статусы доставки и идемпотентность Telegram webhook.
- Добавлен живой интеграционный тест PostgreSQL с проверкой восстановления состояния из нового экземпляра репозитория и конкурентной дедупликации updates.
- Добавлены интеграционные проверки HTTP API: запуск игры, чтение панели, валидация админ-команд и защита Telegram webhook.
- Production запускается только с `DATABASE_URL` и не откатывается незаметно на временную память.
- Добавлен GitHub Actions quality gate с `pnpm check` и `pnpm build`.
- Репозиторий подключён к Vercel, а обязательные server-side переменные добавлены в Preview и Production environments.
